# Anomaly Detection Testing Documentation

This directory follows the testing documentation convention used by the HR Management System reference project.

## Documents

- `security.md` — security test scope and results to be recorded.
- `performance.md` — performance benchmark methodology and results.
- `accessibility.md` — accessibility checklist for the web UI.
- `compatibility.md` — browser/viewport compatibility checklist.
- `usability.md` — task-based usability checklist.
- `exploratory.md` — exploratory testing charter and observations.
- `test-matrix.md` — overall test inventory and execution status.

These documents distinguish **implemented tests** from **executed/passed tests**.
