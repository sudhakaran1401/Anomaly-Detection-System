## 3. Closure Criteria
A defect is closed only when:
1. Reproduction is documented.
2. Root cause is identified or accepted as a limitation.
3. A fix is implemented where required.
4. Relevant automated tests pass.
5. Regression impact is checked.
6. Browser/UI verification is performed where applicable.
7. Documentation is updated where applicable.
