# Smart Anomaly Detection & Classification Platform — SDLC Stage 8: Maintenance & Support

## 1. Scope
Maintenance applies to:
- authentication
- file validation
- feature engineering
- anomaly algorithms
- classification algorithms
- scalers
- explainability
- analytics/charts
- history
- model persistence
- reports/exports
- React frontend
- Django backend
- database/media
- Docker/CI/testing
- benchmark tooling

## 2. Corrective Maintenance
Record issue → reproduce → identify root cause → implement fix → run relevant tests → review → deploy → smoke/regression verify → document closure.

## 3. Adaptive Maintenance
Examples:
- Django/Python/React/Node updates
- Scikit-Learn/XGBoost changes
- browser changes
- OS/container changes
- dependency security updates

ML dependency/model changes should be followed by regression and benchmark verification.

## 4. Perfective Maintenance
Examples:
- clearer anomaly explanations
- improved dashboard charts
- additional export/report features
- improved dataset feedback
- improved responsive UI

## 5. Preventive Maintenance
- dependency review
- security test maintenance
- database/media backup verification
- model artifact review
- benchmark reproducibility checks
- test-suite maintenance
- Docker/CI maintenance
